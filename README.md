# Telegram Bot

Универсальный Telegram бот для управления каналами с автоматическим принятием заявок.

## Возможности

- 🤖 Автоматическое принятие заявок на вступление в каналы
- 👥 Панель администратора с полным управлением
- 📊 Статистика пользователей и каналов
- 📢 Рассылка сообщений всем пользователям
- 🎰 Игровая функция "Испытать удачу"
- 💬 Связь пользователей с администраторами
- ⚙️ Настройка времени автоматического принятия заявок

## Требования

- Python 3.7 или выше
- Библиотеки: `python-telegram-bot`, `pytz`

## Установка

### 1. Установка зависимостей

**Windows:**
```bash
pip install python-telegram-bot pytz
```

**Linux/macOS:**
```bash
pip3 install python-telegram-bot pytz
```

### 2. Настройка конфигурации

Создайте файл `config.json` в корневой папке проекта:

```json
{
    "bot_token": "YOUR_BOT_TOKEN",
    "admin_ids": [YOUR_ADMIN_ID]
}
```

- `bot_token` - токен вашего бота от @BotFather
- `admin_ids` - массив ID администраторов (можно получить у @userinfobot)

## Запуск

### Универсальный способ (рекомендуется)

**Windows:**
```bash
python run_bot.py
```

**Linux/macOS:**
```bash
python3 run_bot.py
```

### Альтернативные способы

**Windows:**
```bash
python main.py
```

**Linux/macOS:**
```bash
chmod +x run_bot.sh
./run_bot.sh
```

## Использование

1. **Для администраторов:**
   - Отправьте `/start` боту
   - Используйте панель администратора для управления

2. **Для пользователей:**
   - Отправьте `/start` боту
   - Подтвердите, что вы человек
   - Используйте доступные функции

## Команды

- `/start` - Запуск бота
- `/cancel` - Отмена текущей операции
